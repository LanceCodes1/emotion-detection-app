# Emotion Detection App

> Python-based emotion detection lab completed through **Justice Through Code** in partnership with Coursera.  
> Focused on API-style function structure, local server debugging, and GitHub submission workflow.

---

##  The Problem

Understanding how to work with someone else's code — reading it, running it, breaking it, fixing it, and documenting what you did — is one of the most important real-world dev skills. This lab was designed to build exactly that.

---

##  What I Did

This was a guided lab project. My work included:

- Setting up and running a local Python server from the command line
- Reading and understanding pre-written API-style function structure
- Running the provided test suite and diagnosing failures
- Debugging local server errors — identifying the issue, fixing it, and documenting what went wrong
- Using AI assistance (Claude/ChatGPT) to understand unfamiliar code behavior — then verifying the explanation myself
- Submitting via GitHub: clone → work → commit → push

---

##  Tech Stack

```
Python 3.x
Flask          — local web server
IBM Watson NLP — emotion detection API (pre-configured in lab)
Git/GitHub     — version control and submission workflow
```

---

##  What I Learned

- How to read and navigate code written by someone else
- How local servers work and how to diagnose common startup errors
- How to run a test suite and interpret pass/fail results
- How to use AI tools responsibly: ask for an explanation, then verify it before trusting it
- The full GitHub submission loop in a structured coursework environment

---

##  What I Would Build Next

- Extend the emotion detection output into a simple dashboard showing emotion trends over time
- Connect it to a Claude prompt: *"Based on this text's emotional tone, suggest a supportive response"*
- Apply this pattern to reentry workshop feedback — surface emotional themes from participant responses to help facilitators adjust their approach
